# Commercial licensing

The [Permaily Personal Use License](../license.md) only allows individuals to use the software for themselves. Any other use needs a commercial license, including:

- use by or for a company, nonprofit, school, university or government body;
- hosting Permaily, or a service based on it, for other people, paid or free;
- distributing modified versions;
- internal business use.

Verifying the public Permaily service never requires a license.

To request a commercial license, open an issue titled "Commercial license" in the repository or contact the maintainer listed on the GitHub organization page. Pricing is set per agreement.
