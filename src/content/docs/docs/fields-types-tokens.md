title: Fields, types and tokens

---

A pack defines which emails match and which fields come back. The SDK turns that into types, so you skip the prompt, the parsing and the validation.

## Fields

Fields sit in the pack, next to its match rules. A `?` marks a field that can be empty.

```yaml
# packs/travel.bookings.yaml
fields:
  is_cancellation: boolean
  cancellation_notes: string?
  refunded: boolean
```

## Types

The SDK turns those fields into types, next to basic info: the sender, date and subject.

```ts
// Generated by the SDK
type TravelBooking = {
  from: string;
  date: string;
  subject: string;
  isCancellation: boolean;
  cancellationNotes: string | null;
  refunded: boolean;
};
```

## Tokens

A token is one processed unit of an email, such as a piece of extracted information. It isn't an LLM token. The [Developer plan](/developers/#pricing) costs $0.01 per 1M tokens, pay as you go.

| You ask for | Tokens per email | 1 million emails cost |
| --- | --- | --- |
| Basic info | 1 | $0.01 |
| Basic info with the three fields above | 3 | $0.03 |

These are the only two counts published, so don't work out a price per field from them.
