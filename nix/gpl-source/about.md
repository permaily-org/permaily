# Source of the third-party programs in permaily.eif

Permaily's enclave image (`permaily.eif`) contains, unmodified, four things Permaily did not write: a Linux kernel, the `nsm.ko` driver and an `init` program, all three prebuilt by AWS and taken from the `blobs/aarch64` directory of [aws/aws-nitro-enclaves-cli](https://github.com/aws/aws-nitro-enclaves-cli) at tag `v1.5.2` (commit `1c496ed730d2dc41ec5bff6df89b4f3185e18840`), and the GNU C Library, which AWS linked statically into `init`. The kernel and `nsm.ko` are under the GNU General Public License version 2 (`COPYING`); the GNU C Library is under the GNU Lesser General Public License version 2.1 or later (`COPYING.LGPL-2.1`); `init`'s own code is under the Apache License 2.0. They are separate programs aggregated in the image with Permaily's program, which is under its own license.

This archive is published with every Permaily release that publishes the image, built by `nix build .#gpl-source` from the same pinned inputs as the image. `manifest.json` lists each program, the SHA-256 of the binary in the image, and which files here are its source; `SHA256SUMS` covers every file. `bun scripts/gpl-source.ts permaily.eif permaily-gpl-source.tar.gz`, in Permaily's repository, checks that this archive describes the binaries that are in a given image.

## How certain each source is

`nsm.ko` (`source: exact`). The source is `aws-nitro-enclaves-sdk-bootstrap-ed24913/nsm-driver/nsm.c`, from [aws/aws-nitro-enclaves-sdk-bootstrap](https://github.com/aws/aws-nitro-enclaves-sdk-bootstrap) at commit `ed24913346a34d719afa2031299253160a2e3460`, with its `Kbuild` and the `Makefile` that builds it. The module's `srcversion` (`D3B5E8FDCD94DD8FF56025B`) is the MD4 digest the kernel's `modpost` computes over the module's source, and computing it over this `nsm.c` gives the same value (as it does for the file at commit `9a1a825`, where it last changed). It was built against the kernel below (`vermagic=4.14.256-209.484.amzn2.aarch64`), whose source is not available.

Linux kernel (`source: unavailable`). The binary reports `Linux version 4.14.256-209.484.amzn2.aarch64 (mockbuild@ip-10-0-42-103) (gcc version 7.3.1 20180712 (Red Hat 7.3.1-13) (GCC)) #1 SMP Tue Jan 11 21:47:26 UTC 2022`: an Amazon Linux 2 kernel package built by Amazon's build system. Its configuration is here twice, as AWS ships it (`aws-nitro-enclaves-cli/blobs/aarch64/Image.config`) and as AWS publishes it in aws-nitro-enclaves-sdk-bootstrap at the commit that updated it for this kernel (`configs/microvm-kernel-config-aarch64`, byte for byte the same file). AWS does not publish the source of this kernel: the Amazon Linux 2 source repository has `kernel-4.14.256-197.484.amzn2.src.rpm` (SHA-256 `5d3378b93d048ab945d221b8f531e99f0146bdd1b6afd63e12313de4d77710d9`), a different release of the same upstream version, and no `209.484`; the `Makefile` and `linux-url` of aws-nitro-enclaves-sdk-bootstrap build from `linux-4.14.204`, not the version of this binary. Permaily cannot give the complete corresponding source of this kernel, and plans to replace it with a kernel built from source in its own build.

`init` (`source: aws-stated`). The source is `aws-nitro-enclaves-sdk-bootstrap-203242d/init/init.c` with its `Makefile`, at commit `203242d54e4fbb9b5d57b49e73c947226e08ce82` (tag `v1.0.0`): AWS replaced the blob on 2024-05-22, 25 minutes after merging that commit, citing it. The binary was built with `GCC 11.4.1 20230605 (Red Hat 11.4.1-2)` and is not reproducible from this source, so the correspondence rests on AWS's word.

GNU C Library in `init` (`source: unavailable`). `init` is linked statically (`-static`) with the GNU C Library. The binary does not record which release, and AWS does not say. The LGPL asks for the library's source and for what is needed to relink `init` with a modified library; `init.c` is here, the exact library source is not. Permaily plans to replace this `init` with one built from source in its own build.
